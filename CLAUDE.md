Once a direction is agreed, run its follow-ups (diagnostics, replicates, the next variant, queueing work so both GPUs stay busy) without asking again, and report what started.
- **Plain English.** Explain results, recipes and plans in everyday words. Keep config flags, run names and coined terms out of user-facing explanations (they belong in logistics.md and job files); if a term is unavoidable, say what it means.

No digit-level breakdowns (ones / tens / carry digit) or other partial scores in user-facing explanations; keep those in `logistics.md` if needed for diagnosis.

- **Simple, end-to-end fixes.** When training breaks, use the simplest change that keeps every gradient flowing (a loss weight, a target, a plain formula). No gradient-blocking tricks or extra machinery; if a frozen or blocked variant is run at all, label it as the not-end-to-end comparison.
