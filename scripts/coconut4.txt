# Coconut on the byte H-Net, read-out from the last thought (2026-11-20; --read thought, latents/coconut.py).
# Why: with a separate <stop> position (coco-c1q...) one hidden calculation is learned (96%) but the second stalls at
# the tens digit (20% after 7000 steps): the last calculation is done at <stop>, whose output is never fed back, so the
# thoughts do not hold the first hidden value in full (probe: tens digit 16%). Here the decoder reads the output at the
# last thought, so the state that writes the next step at stage s is the new thought of stage s+1.
# Whole curriculum from the written-reasoning model; a stage ends when the number needed from the thoughts is right on
# 90% of 200 quick-eval problems (checked every 250 steps) or after 8000 steps. Then the full eval (2000 problems).
# Run:  python scripts/run_jobs.py scripts/coconut4.txt --gpus 1
python scripts/coconut_train.py --init runs/C-B1-plain-cot --name=coco-rt --c 1 --read thought --stages 7 --stage_steps 8000 --eval_every 250 --advance_at 0.9
barrier
sh python scripts/coconut_eval.py runs/coco-rt --n 2000 > logs/coconut/coco-rt.txt 2>&1
